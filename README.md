# 📄 Kubernetes JavaScript SDK Docs (Unofficial Mirror - v1.4)

> [!WARNING]
> **DISCLAIMER**: This project is **NOT** an official Kubernetes or CNCF (Cloud Native Computing Foundation) publication. It is a community-maintained documentation mirror built directly from the [official GitHub repository](https://github.com/kubernetes-client/javascript) at version **v1.4**.

## 🎯 Intent

When practicing **Vibe Coding** (AI-driven programming), the accuracy of the context is paramount. Currently, the official online documentation for `kubernetes-client/javascript` is significantly outdated. This causes LLMs like Claude, Cursor, and GPT-4 to generate incorrect code based on deprecated APIs.

The goal of this site is to provide a **100% faithful documentation mirror** generated from the v1.4 source code to:

1. **Eliminate AI Hallucinations**: Provide type definitions and method signatures that match the actual SDK source.
2. **Optimize RAG Retrieval**: Use clean Markdown and HTML structures, making it easy to integrate into AI knowledge bases.
3. **Empower Cloud-Native Development**: Provide a reliable reference for Node.js engineers practicing automation and platform engineering within Kubernetes.

---

## 🚀 How to use for Vibe Coding

### For Cursor / Claude Users

You can add the URL of this mirror directly to your AI assistants:

* **Cursor**: `Settings` -> `Features` -> `Docs` -> `Add new doc` -> Enter this site's URL.
* **Claude Projects**: Convert key API pages to Markdown (e.g., via Jina Reader) and upload them to your Project Knowledge.

### Local Documentation Consumption

If you prefer offline access, check the `docs/` directory in this repo. It contains pure **Markdown** files generated via `typedoc-plugin-markdown`, which are perfect for importing into **Obsidian** or other RAG systems.
